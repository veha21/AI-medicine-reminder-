# 💊 AI Medicine Reminder

## Project Overview
A Python-based application designed to manage medicine schedules and provide reminders through WhatsApp notifications.

## Technologies Used
- Python
- PyWhatKit
- WhatsApp Web

## Features
- Medicine reminder scheduling
- WhatsApp notification integration
- Automated reminder functionality

## How to Run
1. Install Python and the required libraries.
2. Open the project in VS Code.
3. Run the Python file.
4. Follow the instructions to configure reminders.

## Disclaimer
This project is developed for educational purposes and does not replace professional medical advice.
